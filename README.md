# 問題児ティア表 Bot（Discord・個人開発・運用中）

Discord サーバーの「やらかし発言」を、メンバーの投票で裁いてポイント化し、ランキングにする Bot です。
発言に返信して Bot をメンションすると投票が立ち、1分後に Yes の人数ぶんポイントが入ります。
上位3名には自動でロールが付き、1位のニックネームには 👑 が付きます。

| | |
|---|---|
| 担当 | 仕様の整理・設計・実装・テスト・運用（すべて一人） |
| 期間 | 2026年9月〜（運用中） |
| 規模 | Python 約2,250行 / テスト27件 |
| 主な技術 | Python / discord.py / SQLite |
| 実行環境 | Windows 11（自宅PC・タスクスケジューラで常駐） |

使い方（参加者向けの説明書）は [`USAGE.md`](USAGE.md) にあります。

> **注意点**
> - 身内のサーバー1つで使うために作ったもので、誰でも導入できる公開 Bot としては作っていません。今の使い方で十分なので、公開向けの作り込み（導入の手引き・権限の細かい設定・多人数での負荷対策など）はしていません。
> - **サーバーごとの管理はしていません。** 参加者・ポイント・設定は1つのサーバーを前提に持っていて、複数のサーバーに入れるとデータが混ざります。
> - Windows の PC で常駐させる前提です（起動・停止のスクリプトは PowerShell）。

## できること

| 機能 | 内容 |
|---|---|
| 通報 | 発言に返信して Bot をメンションするだけ。7日より前の発言・自分・Bot・未参加者は通報できない |
| 投票 | Yes / No のボタン。締切まで押し直し自由、途中経過（内訳）は伏せて投票済みの人数だけ見せる |
| 締切の延長 | 締切30秒前に票が動くと +30秒（最大2分）。「残り数秒で一斉に押して逆転」を防ぐ |
| ポイント | Yes の人数ぶん。1件の上限・満場一致ボーナス（殿堂入り）・明らかな言いがかりへの返し点つき |
| ランキング | `/tier` で表示。上位3名にロールを自動で付け替え、1位は 👑 つきのニックネームに |
| 管理 | 参加者の追加・除外、ポイントの手動調整、設定の読み直し（再起動不要） |

## 設計で工夫したところ

### 1. 点数計算はテストで固める
点数がおかしいと、遊びの Bot はすぐ信用を失って使われなくなります。
そこで **集計を Discord や DB から切り離した純粋関数**（`tally.py`）にし、ここだけはテストで固めました。

```
Discord 層（イベント・ボタン・表示）   bot.py
        ↓
集計（状態を持たない純粋関数）         tally.py   ← テスト18件
        ↓
保存（SQLite）                         db.py
```

### 2. PC が落ちても票を失わない・二重に数えない
自宅の Windows PC で動かしているので、アップデートなどで落ちる前提で作っています。

- **票はボタンが押された瞬間に DB へ書く**。メモリに溜めない。主キーを（投票, 投票者）にして、押し直しは上書きで済ませる
- 締め処理は投票の状態（受付中 → 集計済み）の遷移でガードし、**再起動しても二重に加点しない**
- 締切をまたいで止まっていた投票は、票が途中で切れているので**無効**にする
- 二重起動はポートを握って防ぐ。2つ目は起動せずに終わる

### 3. ルールの抜け穴を先に塞ぐ
- **参加は本人の意思で（オプトイン）**。勝手に載せられる人が出ないようにし、未参加者への通報は受け付けない
- **抜けてもポイントは消えない**。消えると「下がったら抜けて入り直す」抜け穴ができ、上位ほどそれをやるので表が無意味になる
- 通報した人は投票できない（通報＝1票にしない）。通報された本人も投票できない
- 途中経過を伏せ、締切直前の票には延長で対応して、流れや駆け込みで決まらないようにした

### 4. 遊び方を変えるのに、コードを触らなくていい
成立ライン・1件の上限・満場一致の条件・延長の秒数・上位ロールの名前などは、すべて `config.json` に出しました。
保存して `/reload` すれば、再起動せずに反映されます。

### 5. 余計なものを持たない
発言の本文は保存せず、発言の ID だけを持ちます。誰が途中で票を乗り換えたかも残しません。

## ファイル

| ファイル | 役割 |
|---|---|
| `bot.py` | Discord とのやりとり、投票パネル、再起動後の復帰 |
| `tally.py` | 集計（純粋関数） |
| `db.py` | SQLite のスキーマとクエリ |
| `roles.py` | 上位ロールと 👑 ニックネームの計算 |
| `report.py` / `export_json.py` | ランキングの書き出し |
| `config.json` | 調整用の設定 |
| `test_tally.py` / `test_roles.py` | テスト |
| `run.ps1` / `stop.ps1` | 起動・停止（Windows） |

## 動かし方

```bash
pip install -r requirements.txt
cp .env.example .env      # Bot のトークンと自分の Discord ID を書く
python bot.py
```

Discord Developer Portal で **MESSAGE CONTENT INTENT** を有効にしてください（返信を読むのに必要です）。
`config.json` の `notify_channel_id` に起動通知を送るチャンネルの ID を入れると、起動時に知らせます（空欄なら送りません）。

テスト:

```bash
python test_tally.py
python test_roles.py
```
